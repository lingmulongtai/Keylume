# Bundled acoustic piano

`upright.sf2` is the unmodified FreePats **Upright Piano KW small**, version
2019-07-03. Recorded by Gonzalo and Roberto, edited by Roberto. Published
under CC0 1.0. Original readme and license are in `licenses/piano/` and are
included with the Windows installer and portable archive.

- Project: https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html
- Archive: https://freepats.zenvoid.org/Piano/UprightPianoKW/UprightPianoKW-small-SF2-20190703.7z
- Archive SHA-256: `3bd025e7c2ffa9e6f3f99215ce383c9cebbac991cfbf9be1453cdb4328ec3492`
- SoundFont SHA-256: `cf2a98eb38a32c4954b4b6e2caae4112d62dd8e892eceefdd7942b0e7d01ac2f`

The SoundFont is embedded in the executable so piano playback works offline
without a DAW, account, plugin installation, or external sample path.
