# 音源ライブラリ

4種類の内蔵音源に加え、GeneralUser GS 2.0.3の274音色をカードから選べます。グランドピアノ、エレピ、オルガン、シンセのリード／パッド、ベース、弦・管楽器などを含みます。追加音色を初めて選んだときに共通の音源パック（32,319,396 bytes、約32MB）を取得します。取得後はオフラインで演奏できます。元の4音色はダウンロード不要です。

「SoundFontを追加」では自分の `.sf2` を取り込めます。最大256MB、1ファイル1024音色まで。選んだファイルをアプリの保存場所の `sounds` へコピーし、すべての対応音色を一覧に追加します。同じ内容は重複保存しません。元のファイルを移動しても利用できます。SFZ、SF3、VSTには対応していません。

8ノブの音作りはリバーブ、ディレイ、カットオフ、レゾナンス、コーラス、歪み、ステレオ幅、トレモロです。画面からも調整でき、変更時に音声出力を作り直しません。音源内の独自モジュレーターやGS固有メッセージを完全に再現するものではありません。
