# 実機受け入れチェックリスト

各項目に Windows バージョン、MIDI Services / WinMM shim 状態、ファームウェア応答、DAW バージョン、日時を記録してください。このリポジトリの自動テストが通っても、以下を実機確認済みとは扱いません。

## 接続と LED

- [ ] 61 鍵 DAW ポートが入出力とも正しく選択される
- [ ] Inquiry 応答が診断画面に表示される（メーカーと機種のバイトを保存）
- [ ] 起動から 3 秒以内に 16 パッド・9 フェーダーボタンが点灯する
- [ ] LED マップ検証で RGB の赤・緑・青を確認する
- [ ] 単色候補を B3 / 93 で比較し、存在しない LED を none にする
- [ ] エンコーダーページ下の CC 52 / 68 を比較する
- [ ] DAW Drum の RGB アドレスを確認する
- [ ] レイアウトを書き出し、再起動後も設定を保持する
- [ ] 15 / 30 / 60 fps で欠落・遅延を確認する

## 演奏と共存

- [ ] 鍵盤は DAW の通常の MIDI 入力へ届く
- [ ] モード A でパッドが ch10、ノート 36–51 へ届く
- [ ] パッドの押下・離し・ベロシティゼロ Note On・アフタータッチを確認する
- [ ] パッド保持中のチャンネル / ノート / 転送先変更で、元の音が止まる
- [ ] 仮想ポート削除・再作成後に再接続する
- [ ] DAW から LED を上書きしても、モード A では 3 秒程度で戻る
- [ ] Custom モードに切り替えたらパッドの描画だけが止まる
- [ ] モード B で DAW 起動時に解放し、DAW 終了後 3 秒で復帰する
- [ ] DAW が起動中に Keylume を起動しても、B では最初から待機する

## 常駐とライフサイクル

- [ ] ウィンドウを閉じた後もライティングが続く
- [ ] トレイからウィンドウを再生成し、設定が復元される
- [ ] 2 個目のプロセスを起動しても、常駐コアが重複しない
- [ ] USB 抜き差し後に初期化される
- [ ] スリープ → 復帰後、2 秒以上待って初期化される
- [ ] ロック・アイドル・夜間で減光する
- [ ] 正常終了で消灯・DAW Drum OFF・DAW OFF が送られる
- [ ] 再起動後、Launchkey が通常の MIDI キーボードとして動く
- [ ] 自動起動 ON / OFF とトレイ開始を確認する

## 音声・OLED・持続性

- [ ] PC の再生音にオーディオエフェクトが反応する
- [ ] 音声出力デバイスの切断・変更後、キャプチャを再試行する
- [ ] OLED テキスト・画像と ACK を確認する（無応答時に画像が停止する）
- [ ] B 待機中に OLED メッセージが送信されない
- [ ] 設定破損時にバックアップから復元し、破損ファイルを隔離する
- [ ] 非表示の静止 / アニメーション / 音声プリセットで CPU とメモリを記録する
- [ ] 入力から LED 発光までの遅延を計測する
- [ ] 72 時間のメモリ・ハンドル・スレッド数を記録し、増加がないことを確認する
