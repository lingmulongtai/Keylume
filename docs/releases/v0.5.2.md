# Keylume v0.5.2 Preview

デスクトップへ透過する演奏画面、本体ボタンの受信、OLEDの操作表示を改善しました。v0.5.1のエフェクトによる無音化の修正も含みます。

## 主な変更

- 演奏画面のWindows側の背景効果を解除し、透明背景にブラーや暗い色が残る問題を修正。
- MIDI練習の再生で選択モニターを自動表示。独立した操作パネルからMIDI読込・再生・停止・シーク・速度・位置合わせを操作できます。クリック透過中も操作でき、隠す／再表示に対応。
- 実機から記録した通常MIDI側の中央左右・Undo・Record・Metronome・Capture MIDI・Quantise、Play/Stopの信号を受信。短い押下の表示も改善。
- ホームのノブに値の円弧、フェーダーにレベルバーと数値を追加。
- OLEDへエフェクト名・音量・現在値・切替先の音色／キット／ライティング名を一時表示。表示時間と、操作後の空白／プリセット表示を設定できます。
- コントローラーの本体図をクリックして割り当てを編集。通常MIDI側のCustom CCもMIDI Learnへ対応。BPMをノブ／フェーダーへ割り当てられます。
- 独立メトロノーム、録音／重ね録りの統一操作、直前の演奏を取り込むCapture MIDI、16分音符のQuantiseを追加。Capture・QuantiseもUndo可能。
- 重ね録り切替で長い音が途切れる問題と、Capture後の音の解放記録を修正。

## ダウンロード・更新

- `Keylume_0.5.2_x64-setup.exe` — Windowsインストーラー
- `Keylume_0.5.2_windows-x64.zip` — ポータブル版
- `SHA256SUMS` / `build-provenance.json` / `verification.json` — ハッシュ、ビルド元、配布バイナリの自己テスト

アプリの更新設定でPreview通知を有効にすると検出できます。トレイの「終了」で旧版を終了してから更新してください。既存の設定、プリセット、音源を保持し、新しい既定割り当ては未登録のボタンへ追加します。録音とUndo履歴は終了時に消えます。

Settings・Scaleなど本体内で処理されるボタンは、独立したMIDI入力が届く場合のみアプリへ割り当てできます。OLED文字はASCII表示です。録音はメモリ内の簡易ルーパーで、WAV/MIDI書出しは含みません。
