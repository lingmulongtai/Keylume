# Keylume v0.3.0 Preview

Launchkeyの操作をライティング画面へライブ反映し、DAWなしで演奏できるピアノを内蔵しました。

## 変更点

- 8つまみ・9フェーダー・Pitch/Modホイール・サステイン・鍵盤・パッド・DAWボタンの受信状態を表示。相対つまみ、圧力、Touch、Arp/Scaleの機能報告にも対応。
- Playは緑、Recordは赤に固定。単色LEDの輝度変化を表示。
- 無料の **FreePats Upright Piano KW small（CC0）** を同梱。オフラインでピアノを演奏できます。
- ベロシティ、CC64サステイン、Pitch、アプリの±3オクターブ移調、本体Octave変更に対応。
- 音量、出力デバイス、音声バッファ、DAW起動中の自動消音、全音停止を追加。設定を保存します。
- ウィンドウを閉じても演奏を継続。ライティングだけを停止することもできます。
- 切断、スリープ、入力あふれ、出力先変更、画面鍵盤のフォーカス喪失での音残りを防止。

## 使い方

更新後、実機接続を有効にして、ライティング画面の **Upright Piano の電源**をオンにしてください。初回のピアノはオフです。ペダルは標準のサステインCC64で使用します。

- `Keylume_0.3.0_x64-setup.exe` — Windowsインストーラー
- `Keylume_0.3.0_windows-x64.zip` — ポータブル版
- `SHA256SUMS` / `build-provenance.json` / `verification.json` — ハッシュ、ビルド元、配布バイナリの検証

v0.2.0以降はアプリの更新確認から取得できます。インストーラーの実行は手動です。既存の設定・プリセットは保持します。

## 確認範囲

Rust・フロントエンド・Edge操作テスト、Clippy、Windowsビルド、配布バイナリのMock自己テストを公開パイプラインで実行します。ローカルWindowsでは音声出力、サステイン、全音停止、照明停止中の演奏、出力エラーからの復帰、ウィンドウを閉じて再表示したときの演奏継続を確認しました。

実物のLaunchkeyとペダルの演奏感・遅延、各DAWとの共存、長時間稼働は未検証です。Customモードの任意割り当てや物理Octave状態は自動判定しません。ASIO、半踏み、VSTホストは非対応。Windows x64 / WebView2が必要で、コード署名はありません。
