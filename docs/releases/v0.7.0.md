# Keylume v0.7.0 Preview

アイコンに合わせた水色の画面、エフェクト音声の調整、ボタンの待機点灯、ライティングプリセットの拡充を行いました。

- 画面のアクセントをアイコンのミント色に統一しました。
- Drive の効き始めを緩やかにし、共鳴のピークと残響・ディレイ・コーラスの加算を抑えました。直接音のアタックは維持します。保存済みの音作りは同じ設定値でも響きが変わります。
- 指定された4つの単色ボタンと9つのフェーダーボタンに、弱い待機点灯を追加しました。明度ゼロや停止時は消灯します。
- 虹、オーロラ、星、リアクティブ、テンポなどのライティングを追加し、通常プリセットは34種類になりました。保存済みの自作プリセットも保持します。

## 更新方法と確認範囲

旧版をトレイの「終了」で閉じ、Windows x64 インストーラーを実行してください。設定とプリセットは保持されます。未署名の Preview です。

信号テストや MockDevice の確認は、実際の音質や実機の LED の点灯・光量を保証しません。特に右側の上下ボタンは v0.6.1 の実機試験で点灯が確認できなかったため、引き続き実機確認が必要です。DAW 共存や長時間稼働の受け入れも未完了です。
