# Keylume v0.6.1 Preview

Launchkey MK4 61のライティング、ボタン入力、OLED表示、音声処理を修正しました。

## 修正内容

- キーボードレインボーは鍵盤を離してから約0.55秒かけて消えます。和音の混色を音程から一意に決め、不要な白飛びを抑えました。フェード時間と混色方法はプリセットで変更できます。
- 鍵盤の音域をパッドなどの各LED列へ展開し、オーディオバーも各列の端まで表示します。届いた短いボタン押下は連続操作でも取りこぼさず、照明と画面へ反映します。
- 実機の中央左右、パッド左上下、Record、Undo、Metronomeなどが送るDAW入力のCCを受け取ります。ライティングの出力アドレスを変更しても入力のボタン識別は変わりません。
- Scale・Arp・Chord Mapの本体機能との干渉を避けるため、これらの割り当ては初期状態で無効です。以前の設定は保持し、実験的な設定を明示して有効にできます。本体側の表示や動作を完全に上書きする機能ではありません。
- OLED操作表示を固定ページへ変更し、数値が変わった場合だけ差分を送信します。ルーパーの録音・停止などの結果や、楽器がオフで操作できない理由も表示します。
- エフェクトをオフにした音は出力時に常時歪ませず、過大入力だけを抑えます。Driveは4倍の処理とフィルターを通し、高音で折り返す成分を低減します。処理による固定遅延は32サンプルです。

## 更新方法と制約

Windows x64版のインストーラーまたはポータブル版をダウンロードしてください。旧版のKeylumeはトレイの「終了」で閉じてから更新します。設定、プリセット、追加音源は保持します。

ノブ右側の上下ボタンは今回の実機試験で入力を確認できず、2種類のLED出力指示でも点灯しませんでした。未対応として調査を続けます。Scale・Arp・Chord Mapなど本体管理のボタンを完全に上書きするための独立した入力は確認できていません。音源の高低域の品質にはサンプル音源自体とRustySynthの再生方式による限界も残ります。
