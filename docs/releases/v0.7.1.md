# Keylume v0.7.1 Preview

ピアノの音量不足を補うゲイン調整と、MIDI 読み込みの中断処理を改善しました。

- ピアノ設定に 0〜+12 dB のゲインを追加しました。初期値は 0 dB で、既存の音量は勝手に変わりません。まず +3 dB 程度から調整してください。
- ゲインの変更は 20 ms で滑らかに反映します。打鍵の強弱を維持し、ドラム・参照 MIDI の独立した音量は変更しません。強い和音ではリミッターの影響や歪みが生じるため、音量に注意してください。
- MIDI の読み込み中止や画面終了で Worker と待機処理を解放し、中断後の結果が画面に反映されないよう修正しました。
- 開発用に SoundFont のオフライン音量測定例を追加しました。

## 更新方法と確認範囲

既存アプリをトレイの「終了」で閉じ、Windows x64 インストーラーを実行してください。設定とプリセットは維持されます。署名なしの Preview です。

自動テスト・ブラウザ操作・ネイティブ MockDevice の検証は、実機の音質・音量、LED、DAW 共存、長時間演奏を保証するものではありません。今回、実機の聴感評価は行っていません。グランドピアノの音量不足に対してはゲイン調整を追加しており、音源そのものの変更はありません。
