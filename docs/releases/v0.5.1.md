# Keylume v0.5.1 Preview

エフェクトを使って演奏していると突然無音になり、出力先を切り替えても復帰しなくなる問題の修正版です。v0.5.0をご利用の方は更新してください。

## 修正

- コーラスの循環バッファで、端数の丸めが配列の範囲外参照を起こす問題を修正しました。音声スレッドが異常終了し、出力先の変更でも復帰できなくなる経路を防ぎます。
- エフェクト内で異常や非有限値が発生した場合、その音声ブロックは元の音で再生し、エフェクトの内部状態だけを初期化します。ノートやルーパーの録音を保持し、次のブロックでエフェクト処理を再開します。
- 境界値、4種類のサンプルレートで各120秒分の連続処理・ノブ変更、異常時の復旧を回帰テストに追加しました。

## ダウンロード・更新

- `Keylume_0.5.1_x64-setup.exe` — Windowsインストーラー
- `Keylume_0.5.1_windows-x64.zip` — ポータブル版
- `SHA256SUMS` / `build-provenance.json` / `verification.json` — ハッシュ、ビルド元、配布バイナリの自己テスト

アプリの更新確認でPreview通知を有効にすると検出できます。トレイの「終了」で旧版を終了してから、インストーラーを実行してください。既存の設定、プリセット、音源は保持されます。ループ録音とUndo履歴は従来どおり終了時に消去されます。
