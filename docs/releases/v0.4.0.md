# Keylume v0.4.0 Preview

Launchkeyだけで、ピアノ・ドラム・ループ演奏とMIDI練習を楽しめるようになりました。

## 追加と改善

- ピアノ4音色：Upright、Bright Upright、FM Electric、Honky-tonk。無料のCC0音源をオフライン同梱。
- 選択したフェーダー（1〜9）でピアノ音量を調整。初期値は右端の9番。
- 省電力ライティングの不要な再送と位相の飛びを修正。OLED連続切替は最新内容をまとめ、送信待ちによる描画停止を防止。
- 新しい「演奏」画面：弾いた音の軌跡、光・粒・音ごとのカラー、音域・左右端・鍵盤高さの調整。
- 複数モニターへ連続する鍵盤を表示。各画面の負座標・拡大率を扱い、Cで位置合わせ、Escで終了。
- MIDI形式0/1を読み込み、落ちてくる音符に合わせて練習。標準は曲のテンポで進むタイミング採点。正しい音まで待つモードも選択可能。
- 速度、トラック、遅延補正、区間リピート、コンボ・採点表示。
- 16パッドの合成ドラムと簡易ルーパー。4拍カウントイン、1/2/4/8小節、録音・重ね録り・再生・停止・消去。
- 「設定」から楽器の出力先を選択。「Windowsの既定」は約1秒で既定出力の変更に追従し、録音したループを保持。

## 使い方

ピアノをオンにし、「演奏」タブを開いてください。新しい表示はモニターを選んで「選択した画面に表示」。ドラム／ルーパーは「パッドドラムとルーパー」を開きます。

- `Keylume_0.4.0_x64-setup.exe` — Windowsインストーラー
- `Keylume_0.4.0_windows-x64.zip` — ポータブル版
- `SHA256SUMS` / `build-provenance.json` / `verification.json` — ハッシュ、ビルド元、配布バイナリの自己テスト

v0.2.0以降はアプリの更新確認から取得できます。インストーラーの実行は手動です。既存の設定・プリセットは保持します。

## 対応範囲

MIDIは16MB・50,000音・2時間まで。ループは今回の起動中のみ保持し、ピアノOFF／終了で消去されます。録音書出し、ASIO、VST、半踏みは非対応。実機のフェーダーとパッドには対応するDAWモード接続が必要です。

Windows x64 / WebView2向けのPreviewです。物理Launchkeyの遅延・OLED・省電力表示、Windowsの実際の出力切替／抜き差し、各DAWとの共存、長時間稼働は引き続き受け入れ対象です。コード署名はありません。
