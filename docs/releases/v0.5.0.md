# Keylume v0.5.0 Preview

音色を選び、本体のノブで音を作り、デスクトップに演奏の光を重ねられるようになりました。

## 追加と改善

- 音源カードに検索・カテゴリ・お気に入りを追加。グランドピアノ、シンセリード、パッド、ストリングスなどGeneralUser GSの追加274音色を、初回選択時に約32MBのパックとして取得。既存4音色は引き続き同梱。
- 自分のSF2をインポートして全プリセットを選択。ダウンロードはサイズ・SHA-256・音源構造を検証し、キャンセル・再試行・修復に対応。
- 8ノブにReverb / Delay / Cutoff / Resonance / Chorus / Drive / Width / Tremolo。演奏中に音を調整して保存。
- 6ドラムキットと、各パッドの音種・音程・減衰・音量・左右位置の編集。パッド左の上下でキット、ノブ右の上下で音色、中央の左右でライティングを切替。
- 演奏／デスクトップ別のカスタム割り当て。右端のフェーダー下ボタンでモード切替。ショートカット、メディア、アプリ／URL起動、Pitchホイールでスクロール、MIDI Learn。
- ルーパーの録音・重ね録り・消去を最大8段階Undo。本体Undoは演奏中にルーパー、デスクトップではCtrl+Z。
- 透明・最前面・クリック透過の演奏画面。バー／鍵盤／情報を独立して隠し、エフェクトだけを表示。本画面とトレイから位置合わせや終了へ戻れます。
- 火花、炎、オーロラ、波紋、レーザー、雪を含む10種類の演出。黒鍵は暗く細く、白鍵は明るく描画。音名なし／英語／ドレミを切替。
- 位置合わせのハンドル判定、ドラッグ更新、ハードウェアと画面を同時操作した際の保存を改善。
- ライティングの「選ぶ」を視覚的なカードに変更。従来の一覧・管理を残し、共存・デバイス・プロファイルは設定内へ整理。

## ダウンロード

- `Keylume_0.5.0_x64-setup.exe` — Windowsインストーラー
- `Keylume_0.5.0_windows-x64.zip` — ポータブル版
- `SHA256SUMS` / `build-provenance.json` / `verification.json` — ハッシュ、ビルド元、配布バイナリの自己テスト

v0.2以降はアプリ内の更新確認から取得できます。Preview通知を有効にしてください。インストーラー実行は手動です。既存設定とプリセットを保持します。

## 使い始める

ライティング画面で楽器をオンにして、音色名の横の「選ぶ」を開きます。「音作り・8ノブ」で音を調整し、「コントローラー」で本体操作を変更します。「演奏」では背景透明とクリック透過、バー／鍵盤の表示を選べます。

- [本体の初期割り当てとカスタマイズ](https://github.com/lingmulongtai/Keylume/blob/v0.5.0/docs/controller.md)
- [透過表示・位置合わせ・ドラム・Undo](https://github.com/lingmulongtai/Keylume/blob/v0.5.0/docs/performance.md)
- [検証結果とコミット一覧](https://github.com/lingmulongtai/Keylume/blob/v0.5.0/docs/verification-v0.5.0.md)

Windows x64 / WebView2向けのPreviewです。物理Launchkeyの全操作、USB遅延、ペダル、LED/OLED、DAWごとの共存、実際の既定出力切替・抜き差し、長時間稼働は引き続き実機受け入れ対象です。コード署名、ASIO、VSTホスト、仮想ゲームパッド、録音のファイル保存／書出しは含みません。ループとUndo履歴はピアノOFF／終了で消去されます。
