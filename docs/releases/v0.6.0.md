# Keylume v0.6.0 Preview

左右の手を分けるMIDI練習と、自動伴奏・試聴を追加しました。デスクトップへクリックを通す演奏表示、操作パネル、本体操作とOLEDも改善しました。

## 主な変更

- MIDIのトラック名・同時刻の音域・前後の音の位置から左右の手を推定。トラックごとの手動指定と音域による分割も可能です。
- 両手／右手／左手で待機・採点を切替。左右の色を独立して設定でき、片手練習の対象外はグレー、試聴では両手を色分けします。
- 反対の手だけの自動伴奏、全パート再生、採点しない「聴く」モードを追加。MIDI音声のオン／オフ、ライブ演奏と独立した音量、±1,000msの音声タイミングを調整できます。
- 音待ち中の伴奏、冒頭の早めた音声、遅らせた曲末尾、同音の重なり、一時停止・シーク・出力再接続の音声処理を改善。
- 位置を固定した演奏画面は常にデスクトップへクリックを通します。位置合わせ時だけ解除。独立した操作パネルから再生・停止・手・伴奏・音量・タイミングを操作できます。
- デスクトップモードでも標準で鍵盤演奏を継続。フェーダー8のWindows既定出力音量、ホームの割り当てホバー表示を追加。ピアノ音量のフェーダー変更時は競合する割り当てを解除します。
- ライティング一時停止中もボタン・モード通知を受信。手動のライティング変更が自動プロファイルに上書きされる問題を修正。
- Scale／Arp／Chord MapのFeature Controls通知で割り当てを実行し、本体機能を戻す処理を追加。問い合わせ応答やリセット通知は押下として実行しません。
- OLEDのノブ／フェーダーの本体ポップアップとの競合を抑制。操作名・値を設定した時間まで更新し、期限後に空白／プリセットへ戻します。終了・DAW譲渡では本体設定を復元します。

## ダウンロード・更新

- `Keylume_0.6.0_x64-setup.exe` — Windowsインストーラー
- `Keylume_0.6.0_windows-x64.zip` — ポータブル版
- `SHA256SUMS` / `build-provenance.json` / `verification.json` — ハッシュ、ビルド元、配布バイナリの自己テスト

更新設定でPreview通知を有効にすると検出できます。旧版はトレイの「終了」で閉じてから更新してください。設定・プリセット・音源は保持します。新しい既定割り当ては未登録の操作子へ追加し、変更済みの割り当ては維持します。録音とUndo履歴は終了時に消えます。

手の自動推定には曖昧さがあり、交差や特殊な譜面は手動修正が必要です。MIDI音声は現在選択した音源でノートを鳴らす機能で、ファイル内のGM音色・ペダル・全CCを再現するプレイヤーではありません。内蔵ピアノをオンにして使用してください。

Scale／Arp／Chord Mapは本体の確認応答が届く場合に対応します。Settings・Octave・Fixed Chordなど、独立した入力通知がない操作まで自由に上書きする機能ではありません。OLED文字はASCIIです。全ボタン・OLEDの視認・長時間稼働の実機受け入れは未完了です。
