# Keylume v0.1.0 Preview

Launchkey MK4 61 向けの非公式ライティングコントローラー、最初の Windows プレビュー版です。Novation / Focusrite とは関係ありません。

## ダウンロード・起動

- `Keylume_0.1.0_x64-setup.exe`: Windows 用インストーラー
- `Keylume_0.1.0_windows-x64.zip`: 展開して `Keylume.exe` を実行するポータブル版
- `SHA256SUMS`: ダウンロードしたファイルの SHA-256
- `build-provenance.json`: ビルド元コミットとツールのバージョン
- `verification.json`: 配布バイナリの MockDevice 自己テスト結果

Windows 11 x64 と WebView2 Runtime が必要です。**コード署名はありません。** インストーラーは WebView2 未導入時に導入を案内します。

初回は MockDevice によるプレビューです。「デバイス」で MockDevice を OFF にすると実機の DAW ポートを探します。× で閉じてもトレイで常駐し、終了はトレイメニューから行います。

## 主な機能

- 18 エフェクト、レイヤー合成、ペイント、ゾーン、13 プリセット
- デバイスキャンバス、プリセット保存・入出力、プロファイル自動切替
- Windows 常駐、トレイ、自動起動、ホットプラグ
- ライティング優先 / DAW ハンドオフ、既存ループバックへの MIDI 入力転送
- WASAPI 音声連動、OLED テキスト・画像、LED マップ検証
- 依存ライブラリのライセンス全文をインストーラーと ZIP に同梱

## 検証と制約

公開パイプラインで Rust テスト、UI テスト、ブラウザー操作テスト、Clippy、Windows ビルド、配布用実行ファイルの7項目の自己テストを実行します。

**実機受け入れ・各 DAW との共存・スリープ・72 時間連続稼働は未検証です。** 自己テストは MockDevice によるもので、実機の発光を検証したものではありません。英語 UI、Phase 3 などの未実装項目があります。
