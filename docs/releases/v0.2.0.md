# Keylume v0.2.0 Preview

UI と Launchkey MK4 61 の本体図を修正し、自動アップデート確認を追加しました。

## 変更点

- 装飾を抑えたダークUIと上部ナビゲーションに変更。編集領域と設定の読みやすさを優先しました。
- **61鍵モデルの公式写真・ハードウェア図に合わせて本体図を再構築**。左のホイール・9フェーダー、中央OLED、右の8エンコーダーと16パッド、トランスポート、61鍵の位置・比率を修正しました。
- エディターとプリセット一覧で同じ本体図を使用。光の発生位置、選択範囲、200%までの拡大表示を揃えました。
- 既定のv0.1.0レイアウトを安全に移行。カスタムMIDIアドレス、LED種別、検証状態を保持し、手動で座標を変更したレイアウトは維持します。
- 起動時と12時間ごとにGitHub Releasesを確認し、新しいWindows版を画面上またはトレイ常駐時に案内します。手動確認、自動確認のオフ、Preview版の選択、「あとで」に対応しました。

## インストール

**v0.1.0 からは、この版を手動でインストールしてください。自動更新確認は v0.2.0 以降の機能です。** 更新通知からリリースページを開き、ダウンロードしたインストーラーをご自身で実行する方式です。

- `Keylume_0.2.0_x64-setup.exe` — Windows インストーラー
- `Keylume_0.2.0_windows-x64.zip` — 展開して `Keylume.exe` を実行
- `SHA256SUMS` / `build-provenance.json` / `verification.json` — ハッシュ・ビルド元・配布バイナリの検証結果

Windows 11 x64 / WebView2 Runtime が必要です。コード署名はありません。既存設定は `%APPDATA%\Keylume` に保持します。

## 検証と制約

公開パイプラインでRust・フロントエンド・Edge操作テスト、Clippy、Windowsビルドと配布バイナリの7項目のMockDevice自己テストを実行します。更新通知の通信は描画とMIDI処理から独立しています。

実機の発光、MIDIアドレス、OLED、各DAWとの共存、スリープ、72時間稼働は引き続き未検証です。本体図の修正は実機の動作確認を代替するものではありません。Novation / Focusriteとは関係のない非公式ソフトです。
