# ピアノとライブ操作表示

## すぐ弾く

1. Launchkey MK4 61 を USB 接続し、Keylume のプレビュー設定をオフにします。
2. ライティング画面の **Upright Piano の電源**をオンにします。初回はオフです。
3. 必要なら「音声と演奏の設定」で出力先を選びます。同梱4音色はDAW・VST・アカウント・インターネット接続不要です。追加音源は初回のみダウンロードします。
4. 鍵盤を弾くと、ベロシティに応じたピアノと既存のリアクティブ照明を一緒に使えます。照明の反応は「鍵盤入力に反応する」とプリセットで調整できます。

同梱音源は FreePats **Upright Piano KW small / Bright Upright / FM Piano #2 / Honky-tonk Piano FB small** の4種類。128ボイスまで発音します。CC0 1.0 の原文・クレジットを配布物に含めています。[出典・ハッシュ](../resources/piano/SOURCE.md)

## 音源ライブラリ

音色名の右にある「選ぶ」で、検索・カテゴリ・お気に入り付きのカード一覧を開きます。GeneralUser GSの追加274音色には、グランドピアノ、エレクトリックピアノ、オルガン、シンセリード、パッド、ストリングス、ブラスなどがあります。

未取得のカードを選ぶと、共有する約32MBのパックを一度ダウンロードします。取得後は全274音色をオフラインで切り替えられます。進捗表示・キャンセル・再試行に対応し、サイズ・SHA-256とSoundFont構造の確認後に保存します。破損が疑われる場合は「追加パックを確認・修復」を使ってください。同じパック内の音色切替とエフェクト変更では音声出力を再起動しません。別の音源ファイルへの切替は短い読込と無音を伴います。

「SoundFontを追加」で自分のSoundFontも追加できます（1ファイル256MiB、1,024プリセットまで）。元ファイルをアプリの保存領域へコピーするため、読込後に元ファイルを移動しても使えます。SFZ、SF3、VSTは対象外です。自分で追加した音源の利用条件は配布元を確認してください。

追加パック: [GeneralUser GS / S. Christian Collins](https://github.com/mrbumpy409/GeneralUser-GS)。同梱の[ライセンス原文](../licenses/generaluser/LICENSE.txt)を参照してください。音源キャッシュは`%APPDATA%\Keylume\sounds\`に保存されます。

## 8ノブで音を作る

「音作り・8ノブ」を開くと、Reverb、Delay、Cutoff、Resonance、Chorus、Drive、Width、Tremoloを調整できます。グランドピアノに少量のReverbを加えたり、シンセのCutoffを絞って音を変えられます。初期状態は原音中心です。

本体の8ノブへ同じ順番で割り当てています。値はなめらかに追従し、楽器の生演奏とループ演奏へ適用します。ドラムにはこのエフェクトをかけません。変更は保存され、音色を切り替えても現在の音作りを維持します。[操作子の変更](controller.md)

## フェーダーで音量を操作

「音声と演奏の設定 → 音量を操作するフェーダー」で1〜9または割り当てなしを選べます。初期値は右端の9番。LaunchkeyのDAW Volumeモード（チャンネル16のCC5〜13）に対応します。Customモードは自動推測しません。照明停止やDAWへのハンドオフでDAWポートが閉じている間は物理フェーダー／パッドの入力を受け取れません。

## ペダルとオクターブ

- サステイン端子に接続したペダルは、標準の **CC64** 設定で使用してください。64以上を踏み込み、63以下を解除として扱います。半踏みは非対応です。
- 本体の Octave ± は、受信するノート番号が変わるため、そのまま音程に反映されます。
- アプリの Octave は追加の −3〜+3 オクターブ移調です。本体のオクターブをさらに加算します。変更時は全音を解放し、MIDI範囲外の音は発音しません。
- Pitch ホイールにも反応します。VSTのホスト機能はありません。
- 画面の鍵盤はクリック、フォーカスして Enter / Space でも演奏できます。画面を離れると画面から鳴らした鍵盤だけを解放します。
- 音が残った場合は **全音停止**。ペダル保持もリセットします。

## 常駐・DAW・出力

ピアノのオン／オフ、音量、移調、出力先、バッファは保存されます。ウィンドウの × は表示を閉じるだけなので、本体の鍵盤で演奏を続けられます。トレイの「終了」でピアノも終了します。Windows起動時に使う場合は設定の自動起動を有効にしてください。

上部の「一時停止」はライティングの停止です。ピアノをオンにしていれば鍵盤入力と音声は継続します。「DAW 使用中はピアノを消音」は初期状態でオンです。「DAW に譲る」モードでは、DAW使用中に鍵盤ポートも解放します。WindowsのMIDIドライバーが複数アプリでの共有に対応しない場合、鍵盤入力欄にエラーを表示します。

音声は Rust / CPAL / WASAPI で処理し、実機MIDIを画面の描画ループを経由せず音声キューへ送ります。バッファ指定がドライバーに受理されない場合は既定値へフォールバックし、実際の音声コールバックのフレーム数を表示します。これは端から端までの遅延測定ではありません。音切れがあれば512または1024 samplesを試してください。ASIOには対応していません。

出力デバイスのエラーは表示して再試行します。出力先変更・ピアノ停止・USB切断・スリープ・入力キューあふれでは音声を解放します。出力先は「設定 → 楽器の音声出力」または「音声と演奏の設定」で変更できます。「Windowsの既定に自動追従」では約1秒ごとに実際の出力先IDを確認し、変更に追従します。切替時は短い無音が入ります。デバイスを明示指定した場合は既定変更に追従しません。ループの録音内容は出力切替後も保持します。

## 画面へ反映する操作

| 操作                              | 表示                                   |
| --------------------------------- | -------------------------------------- |
| DAWモードの8つまみ                | 絶対CC値、Transportモードの相対回転    |
| Volumeモードの9フェーダー         | 最後に受信した位置                     |
| Pitch / Modulation                | ホイールの受信位置（Modは既定CC1）     |
| 鍵盤・パッド・公開仕様のDAWボタン | 押下／解放、ベロシティ、圧力           |
| サステイン                        | CC64の踏み込み状態                     |
| Touchイベント                     | 受信時につまみ・フェーダーを強調       |
| Arp / Scale                       | 機能状態の応答を受信すると本体図へ反映 |
| Play / Record                     | 緑／赤の固定色。単色LEDの輝度に追従    |

画面は最大30回/秒で更新します。未操作フェーダーの物理位置やエンコーダーの絶対角度を装置へ問い合わせることはできないため、未取得は薄く表示します。相対つまみの目盛は受信した回転量の可視化です。

独自に割り当てたCustomモードのCC/NRPNを、どの物理操作子か自動判定することはできません。受信メッセージは入力欄とMIDIモニターに表示します。Octave/Transposeボタン自体の状態は公開仕様に報告がないため推測しません。図の鍵盤はC2〜C7の受信ノートを表示し、範囲外のノートは上部のNote欄で確認できます。鍵盤・ホイール・つまみ自体が実機で発光する機能ではありません。
