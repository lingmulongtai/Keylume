# 演奏画面・練習・ドラムとルーパー

## 弾いた音を表示する

「演奏」→「ライブ表示」を選びます。音符は鍵盤から上へ伸び、サステイン中は軌跡がつながります。スタイルはシンプル、やわらかい光、光の粒、音ごとのカラー、火花、炎、オーロラ、波紋、レーザー、雪の10種類。色、粒子量、ガイド、軌跡の秒数を調整できます。音域は初期状態でC2〜C7の61鍵です。本体のオクターブに合わせて表示音域を変更してください。

黒鍵のバーは白鍵の64%の幅で暗く、白鍵は明るく描画します。音名は非表示／英語（C4など）／ドレミ（ド4など）を選択できます。ライブとMIDI練習の両方に適用します。

表示と発音は別です。内蔵音源を使う場合はピアノの電源をオンにします。実際に受信した音だけを表示するため、物理鍵盤やペダルの未取得状態を推測しません。

## 2画面に合わせる

1. Windowsのディスプレイ設定で2台の左右配置と高さを合わせます。
2. 「表示するモニター」で両方を選び、「選択した画面に表示」を押します。
3. 「鍵盤の位置合わせ」で、左右の縦線を実物の鍵盤の両端へ、横線を打鍵位置へドラッグします。
4. 演奏画面でも **C** で位置合わせ、**Esc** で演奏画面を閉じられます。

各モニターに専用の枠なし画面を開き、Windowsの物理ピクセル座標で1つの鍵盤を描画します。左側モニターの負座標と異なる拡大率に対応。高さが異なる場合は、開くときに鍵盤の初期位置を共通の可視範囲へ調整します。段違い／縦配置では連続する鍵盤を作れない場合があります。ケーブルの抜き差し後は「画面を再検出」でモニターを選び直してください。次の表示・再生操作では位置・解像度・拡大率を再確認して画面を作り直します。

位置・色・音域などは保存します。選択モニターの一覧は開くときに再取得します。画面を閉じてもピアノとループは常駐します。ベゼル幅そのものは自動測定しません。

## デスクトップにエフェクトを重ねる

「背景を透明にする」で、黒い背景を消してデスクトップへ演出を重ねます。Windows側のMica/Acrylicも解除し、背景にブラーや暗い色を加えません。「ノートのバー」「鍵盤」「情報表示」はそれぞれ独立して消せます。バーと鍵盤を消して火花や光の粒を選ぶと、打鍵位置からエフェクトだけが立ち上がります。画面内のプレビューでは透明部分を市松模様で示します。

位置を固定した演奏表示は常にクリックを背面へ通すので、最前面の演出を表示したまま下のアプリを操作できます。位置合わせを再開するには、**Keylume本画面の位置合わせボタン**か、**トレイの「演奏表示の位置合わせ / 操作を解除」**を使ってください。編集中はクリック透過を一時解除します。再び演出へ戻す操作で透過を再開できます。表示を閉じる操作も本画面とトレイにあります。クリック透過中は演奏画面へキーボードフォーカスがないため、C / Escだけを復帰手段にしないでください。

位置合わせはポインターから近いハンドルを選び、ドラッグ中はその場で描画して設定保存をまとめます。鍵盤自体を非表示にしても、編集中のガイドは表示します。

## MIDIで練習する

「MIDI練習」→「MIDIを読み込む」で`.mid`/`.midi`を選択します。曲を持っていない場合はKeylumeオリジナルの「お試し曲」を利用できます。

再生を押すと、選択したモニターの演奏画面を自動で開きます。独立した操作パネルからMIDI読込・再生・一時停止・停止・再生位置・速度・位置合わせを操作できます。演出がクリック透過中でも、このパネルは操作できます。タイトル部分をドラッグして移動し、「隠す」またはAlt+F4で隠せます。本画面の「演奏操作を表示」や位置合わせ開始で再表示できます。

- 標準は**曲のテンポで進む・タイミング採点**。PERFECT ±80ms、GOOD ±160ms、LATE ±250ms。早い音も同じ幅で判定し、符号付きのずれを表示します。音違いはWRONG、未演奏はMISS。
- **正しい音まで待つ**では、練習対象に選んだ手の和音をすべて弾くまで停止します。このモードでは入力遅延補正を採点へ適用しません。
- 再生前に先読み時間（最大3秒）のカウントを入れます。速度は0.25〜2倍、表示の先読みは1.5〜12秒。テンポ変更を含むMIDIを曲の時間に変換して表示します。
- トラックを選択し、A/B秒で区間リピートできます。ドラムトラックは初期選択から外します。同時刻の同じ音が複数トラックにある場合は1回の打鍵で判定します。
- 再生位置移動、対象トラック／待機方式／区間の変更は採点をリセットし停止します。単なる一時停止は採点を維持します。ループでは得点を積み上げます。
- 表示音域外の音も選択トラックに含まれていれば採点対象です。トラック選択と音域設定を合わせてください。
- 入力が遅れて判定される場合は「入力遅延の補正」をプラスへ調整します。音声ドライバーと画面の実測遅延を自動校正する機能ではありません。

内蔵ピアノをオンにすると、MIDI音声も現在の音色で鳴らせます。選択したトラックのノートを演奏し、ファイル内のGM音色・ペダルや他のCCを忠実に再現するプレイヤーではありません。ライブ演奏の音量・オクターブ・録音とは独立して再生し、自動演奏をルーパーへ録音しません。SMF形式0/1・PPQ、16MB・50,000音・2時間まで。SMPTEと形式2は非対応。読込は別スレッドで行い、解析は10秒で打ち切ります。MIDIファイルや採点履歴は保存しないため、次回起動時は曲を読み直してください。

## 左右の手と自動伴奏

「練習する手」で両手・右手・左手を選びます。待機と採点の対象を選んだ手に絞れます。左手と右手の色は別々に設定でき、片手練習では対象外の手をグレーで表示します。「聴く」モードでは両手の色を表示します。黒鍵は細く暗く、白鍵は太く明るく描きます。

手の自動推定はトラック名のLeft/LH/左手・Right/RH/右手を優先し、名前がないノートは同時刻の音域と直前の音の位置から分けます。交差する手などは完全には判別できません。各トラックの「自動／左手／右手」指定か、「音域で分ける」の境界音で修正できます。トラック指定は曲を読み替えるとリセットします。

- 「反対の手を自動演奏」では、右手練習なら左手を、左手練習なら右手を鳴らします。両手練習では自動伴奏はありません。
- 「全パートを自動演奏」は選択トラックをすべて鳴らします。「聴く・自動演奏」モードでは採点も待機も行いません。
- 「MIDI音声を鳴らす」は独立してオン／オフできます。MIDI音量はライブのピアノ音量とは別です。
- 「MIDI音声のタイミング」は±1,000ms。プラスは音を遅らせ、マイナスは早めます。練習速度を変えても実時間のmsです。入力採点の遅延補正とは独立しています。マイナスの場合は冒頭を欠かさないための準備時間を入れます。
- 待機中は同時刻まで到達した伴奏を鳴らしてから音価どおりに離し、次の音へ勝手に進みません。一時停止、停止、シーク、曲や設定の変更では自動音を解放します。

メイン画面と別画面の操作パネルで、手・採点方式・伴奏・音量・音声タイミングを変更できます。

## 16パッドのドラム

「パッドドラムとルーパー」を開き、ピアノをオンにします。本体の上段8個・下段8個と同じ順に配置しています。音源はアプリ独自の合成音で、追加ダウンロードは不要です。

| 段   | 左から右へ                                                            |
| ---- | --------------------------------------------------------------------- |
| 上段 | Low tom、Mid tom、High tom、Rim shot、Ride、Bell、Wood low、Wood high |
| 下段 | Kick、Snare、Closed hat、Open hat、Clap、Shaker、Crash、Cowbell       |

ベロシティに反応し、Closed hatは鳴っているOpen hatを止めます。画面ボタンでも試せます。物理パッドは有効なDAWポートからの通常／DrumモードのNote Onに対応。aftertouchや鍵盤の同じノート番号をドラムとは扱いません。ライティング停止、Customモード、DAWへのハンドオフ中は本体パッドを受信できない場合があります。ドラムを鳴らす設定と音量は独立して保存します。

Studio / Sub 808 / Punch 909 / Lo-fi / Glass / Percussionの6キットから選べます。本体パッド左の上下ボタンでも切り替えます。各パッドの音の種類、音程、減衰、音量、左右位置を編集し、キットごとに保存します。ルーパーはパッド番号を記録するので、録音後にキットを変えると再生中のドラムも変わります。

## 簡単なルーパー

1. BPM（40〜240）と1/2/4/8小節、クリックの有無を選びます。4拍で1小節です。
2. **録音**を押すと4拍カウントインし、指定した長さを録音して自動で再生に移ります。
3. **重ね録り**を押すと、再生にピアノ・ドラムを足せます。もう一度押すと重ね録りを終了します。
4. **停止**は内容を保持、**ループを消去**は録音を削除します。別のテンポ／長さで録るときは消去して設定し直します。

本体Recordと画面の録音ボタンは同じ動作です。既存の録音がある場合は重ね録りを開始し、再生中は音を途切れさせず重ね録りを切り替えます。**Metronome**は録音していないときも使用でき、BPM変更がすぐ反映されます。Stopでクリックも停止します。

**Capture MIDI**はピアノがオンの間に弾いた直前の演奏を、設定した小節数分だけ取り込みます。**Quantise**は録音した発音位置を16分音符へそろえ、音の長さを保って解放位置も移します（ループ末尾まで）。どちらもUndoできます。本体と画面のボタンは同じ録音内容を操作します。

鍵盤、ベロシティ、オクターブ、ペダル、Pitch/対応CC、パッドの打撃を記録します。録音済みピアノと生演奏は別の音声合成器を使い、生演奏のNote Offでループの同音が切れることを防ぎます。周回境界では録音側の保持音とペダルをリセットします。長音は周回をまたいで無制限に伸びません。

**Undo**は新しい録音、重ね録り、消去の前の状態を最大8段階戻します。本体Undoも同じ操作です。Undoすると再生を停止して以前の録音内容・テンポ・長さを復元します。Redoはありません。

録音は最大8,192イベント。今回の起動中だけのメモリ保持です。ピアノOFFとアプリ終了で履歴も消去されます。音源ファイル・出力先を手動変更すると停止しますが録音は保持。同じ追加パック内の音色切替では出力を再起動しません。Windows既定出力の自動切替でも録音を保持します。WAV/MIDI書出し、保存、DAW同期、複数独立トラックのミキサーはこの簡易ルーパーにはありません。

## 確認範囲

ブラウザープレビューでは画面・MIDI読込・設定操作を確認できます。発音、採点、独立モニター表示、ルーパーはWindows版で実行します。Launchkey実機のUSB遅延、物理ペダル、OLED・省電力エフェクトの見た目は実機受け入れ対象です。録画／動画ファイル書出しや特定YouTube動画の再現機能は含みません。
