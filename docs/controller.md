# 本体のボタン・ノブを使う

上部の「演奏モード／デスクトップモード」、または右端のフェーダー下ボタン（9番）で切り替えます。「コントローラー」で2つのモードの割り当てを別々に編集できます。デスクトップモードへ切り替えると、楽器・ルーパーと保持音を停止します。録音内容は保持し、ライティングと本体への接続は継続します。

## 初期割り当て

| 操作子                      | 演奏モード                                                      | デスクトップモード                             |
| --------------------------- | --------------------------------------------------------------- | ---------------------------------------------- |
| ノブ1〜8                    | Reverb、Delay、Cutoff、Resonance、Chorus、Drive、Width、Tremolo | 未割り当て                                     |
| ノブ右側の上下              | お気に入りの前／次の音色                                        | 未割り当て                                     |
| パッド左側の上下            | 前／次のドラムキット                                            | 未割り当て                                     |
| 中央の左右                  | 前／次のライティング                                            | 前／次のメディア                               |
| Undo                        | ルーパーを1段階戻す                                             | Ctrl+Z                                         |
| Play / Stop / Record / Loop | 再生／停止／録音・重ね録り／重ね録り切替                        | メディア再生停止／停止／未割り当て／未割り当て |
| フェーダー下1〜8            | お気に入り1〜8                                                  | 1:音量↓、2:音量↑、3:ミュート、4〜8:未割り当て  |
| フェーダー下9               | モード切替                                                      | モード切替                                     |
| Pitchホイール               | ピッチベンド                                                    | 上下スクロール                                 |

音色の上下切替は取得済みのお気に入りを巡回します。お気に入りが空なら取得済みの全音色を使います。未取得の音色は画面の音源ライブラリで一度選択してダウンロードしてください。

ノブはDAW Plugin / Mixer / Sendsの絶対CC、Transportの相対回転に対応します。コントローラーを有効にして接続した際にPluginノブ・Volumeフェーダーモードを設定します。実機でCustomへ切り替えた後は自動で上書きしません。従来のピアノ音量フェーダー設定はVolumeモードで引き続き使え、明示的に割り当てた機能が優先します。

## 好みの操作へ変更する

1. 「コントローラー」で編集するモードと操作子を選びます。
2. 音色、エフェクト、輝度、音量、ルーパー、モード切替、全音停止、ショートカット、アプリ／URL、スクロールから機能を選びます。
3. 必要な値を入力して「割り当てを保存」を押します。ショートカットは画面でキー入力を記録できます。

CustomのCCやノートは「MIDI Learn」で受信メッセージを登録できます。Learn中に受け取った操作は通常の割り当てを実行しません。学習待機は30秒で解除されます。Octave・Shiftなど、ファームウェア内で処理されアプリに届かないボタンは割り当てできません。

アプリ起動は選択した`.exe`、URLは`http://`または`https://`に対応します。ショートカットは現在の前面アプリへ送ります。最大5キーの同時押しで、順番に複数コマンドを実行するマクロや任意スクリプトではありません。ゲームパッドとしてのアナログ入力を作る仮想ドライバーは含みません。キー入力に対応するゲームにはショートカットを割り当てられますが、各ゲームでの動作は未検証です。

スクロールはホイールの中央付近で停止し、倒す量に応じて速度が変わります。速度倍率を設定できます。切断、ロック、スリープ、割り当て変更、全音停止では継続操作を止めます。MockDeviceではOSへのキー送信・アプリ起動・スクロールを実行しません。

DAWポートを別アプリに譲っている間やライティングを一時停止してポートを閉じた間は、本体ボタンを受信できません。画面側のモード切替を使用してください。

根拠: [Novation DAW mode](https://userguides.novationmusic.com/hc/en-gb/articles/23754923378066-Launchkey-Programmer-s-DAW-mode)、[Feature controls](https://userguides.novationmusic.com/hc/en-gb/articles/23754916107922-Launchkey-feature-controls)。実機の全ボタンとCustom設定の組み合わせは受け入れ対象です。
