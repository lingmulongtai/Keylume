# アップデートの確認

Keylume v0.2.0 以降は、起動から約3秒後と12時間ごとに、このリポジトリの GitHub Releases を確認します。初期設定は「更新を自動確認」「Preview 版も通知する」が両方オンです。設定画面で変更できます。通信失敗時は1時間後に再試行します。

新しい Windows x64 インストーラーがある場合、開いている画面の上部に案内を表示します。ウィンドウを閉じたトレイ常駐中・最小化中はダイアログで案内します。「更新ページを開く」からリリース内容とダウンロードを確認してください。インストーラーの自動実行やアプリの自動置換は行いません。

「あとで」を選ぶと、その版の案内を閉じます。次の新しい版は再び通知します。設定の「今すぐ確認」またはトレイの「アップデートを確認」は、自動確認がオフでも使えます。手動で確認すると、既に閉じた版も再び案内します。

**v0.1.0 には更新確認機能がありません。v0.2.0 は一度手動でインストールしてください。** 以後の更新をアプリから確認できます。既存のプリセット・設定は同じ保存場所を使います。既定の旧本体図だけを新しい61鍵レイアウトに移行し、LEDアドレスや検証状態は保持します。

## 通信と選択条件

- Windows の WinHTTP で `https://api.github.com/repos/lingmulongtai/Keylume/releases?per_page=100` を取得します。アカウントの認証や個人設定の送信はありません。
- HTTPS の証明書検証を有効にし、自動認証・Cookie・リダイレクトを無効化します。各通信段階に5秒のタイムアウト、本文受信ループに30秒の期限、応答本文に2 MiBの上限があります。
- draft は除外し、現在より新しい SemVer を比較します。完全にアップロードされた正しい名前の Windows x64 インストーラーと、このリポジトリの正規ダウンロードURLがある版だけが候補になります。
- リリース一覧の直近100件が対象です。API制限・オフライン・解析失敗はエラー表示にし、「最新版」とは表示しません。
- 通信は専用スレッドで実行し、MIDI送信と描画を待たせません。自動・手動の同時要求は1つの通信にまとめ、手動結果は必ず案内します。
- 確認時刻と閉じた版・通知した版を `%APPDATA%\Keylume\update-state.json` に保存します。更新先URLはAPIの任意文字列を使わず、検証済みタグから公式リポジトリ内のURLを組み立てます。

ネイティブ自己テスト時は自動確認を開始しません。通常のテストはネットワーク不要です。明示的な実通信検証は次で行えます。

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --locked --lib github_release_endpoint_responds_over_verified_https -- --ignored
```
