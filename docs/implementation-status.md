## v0.1 の制約・未実装の細部

- **実機受け入れは未完了。** RGB ID、単色ボタンの有無・種別、DAW Drum、機種識別応答、OLED ACK、継続送信、DAW ごとの挙動は確認待ちです。
- 61 鍵のモデル名と DAW ポートを特定できない場合は送信しません。機種固有 inquiry バイトによる判定は検証待ちです。
- トレイのプリセットメニューは起動時の同梱 8 件です。最近使用履歴への追従と、プリセット色でのトレイアイコン更新は今後の改善です。
- 言語は日本語のみ。English 切替は未実装です。
- エフェクトは共通パラメータと主要な固有パラメータに対応。音名ごとの色表、入力トリガーの個別選択、ノート投影範囲の切替、16 バンド FFT、周波数帯域の詳細編集は未実装です。
- 本体デモは値が未検証かつ本体保存設定のため、プリセットの自動適用では書き込みません。ユーザーの明示操作だけで CC 72 を送ります。
- 同梱のパレット RGB は近似値。ハードウェアエフェクトは単独レイヤーかつ互換性のある色補正設定で使用し、減光や合成時はソフトウェア描画に切り替わります。
- OLED の日本語は文字列では送信できないため、プリセット ID を表示します。bitmap の終端は正規の SysEx 終端 F7 に固定しています。未終端の 7F メッセージは送信しません。
- MIDI 診断モニタは直近 100 メッセージのメモリ内表示です。操作ログはディスク保存しますが、全 MIDI バイト列のファイル記録は未実装です。
- OS 通知は未実装。ウィンドウ表示中のトーストと診断メッセージで通知します。
- 60 Hz 描画 / 設定 fps 送信は実装済みですが、CPU 0.5% / 3%、非表示メモリ 40 MB、入力遅延 30 ms、72 時間連続動作は未計測です。
- スリープ通知から実際の suspend までの解放完了タイミングは実機検証が必要です。復帰世代番号を保持し、コアが suspend 通知を処理する前に停止しても復帰時に再初期化します。
- Phase 3（DAW レイヤー合成、写真キャリブレーション、画面同期、macOS の正式対応、他モデル）は実装していません。

## 仕様からの意図的な補正

- Windows MIDI Services 稼働を WinMM マルチクライアント可否と同一視しません。
- Windows のループバックは A/B の対として案内します。
- モード問い合わせ無応答だけで頻繁な再初期化を行わず、修復は間隔を制限します。Custom モードの選択中はパッド出力を停止します。
- LED 出力は別スレッドに置き、未送信更新をアドレスごとの最新値に統合します。差分フレームを単純に捨てて古い LED 値が残ることを防ぎます。
- 入力キューのオーバーフローを検知した場合は、送信済みのノートを解放してから処理を再開します。
- OS のプロセス・MIDI・音声デバイス列挙は描画スレッドと分離し、遅いドライバーによる描画停止を防ぎます。
